## Cause

The stock SQL summed every `Tran2` record except voucher type 26.
It therefore included a non-stock record (`RecType=4`, `VchType=13`):

| Field | Value |
| --- | --- |
| Item master code | 3838 |
| Branch code | 201 (Khargate) |
| Voucher code | 18852 |
| Voucher number | 88 |
| Voucher date | 2026-09-25 |
| Quantity incorrectly included | 1440 |
| Value incorrectly included | 230400 |

Actual physical movements in this backup use `Tran2.RecType=2`.
The corrected queries select that record type instead of excluding only one
non-stock voucher type. This excludes both the 1440 record and quotation rows
(`RecType=20`, `VchType=26`) without hardcoding an item or quantity adjustment.
